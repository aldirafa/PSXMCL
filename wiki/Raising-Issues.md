If you encounter bugs, discover a corrupted memory card extraction issue, or have a question, please let us know by opening an issue on GitHub.

### How to File a High-Quality Issue

1. **Search First**: Scan existing open and closed issues to check if your concern has already been reported.
2. **Use Clear Descriptions**: State what happened, what was expected, and what version of the library you are using.
3. **Provide a Reproducible Example**: Include a minimal code sample (in F#, C#, or VB.NET) along with any relevant errors, logs, or exception stack traces.
4. **Attach File Context (if applicable)**:
   - If a specific `.mcd` memory card file is causing parsing or repacking errors, specify the emulator or editor that generated the file, or provide a minimal replica if possible.
